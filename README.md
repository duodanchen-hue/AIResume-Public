# AI Resume Agent

AI Resume Agent is an LLM-based web application for generating and optimizing structured resumes based on user information and target job requirements.

## Live Demo

https://airesume-z9yn.onrender.com

> The Render free service may take a short time to start after a period of inactivity.

## Features

- Collects education, project, skill, and career information
- Generates structured resume content with an LLM
- Adapts resume content to target roles
- Supports resume analysis and optimization
- Provides document export
- Includes a browser-based user interface

## Tech Stack

- Python
- FastAPI
- DeepSeek API
- HTML, CSS, and JavaScript
- Render
